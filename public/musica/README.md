# Música de GradoPro

Coloca aquí únicamente archivos MP3/M4A/OGG que tengas permiso para publicar y utilizar.

Desde GitHub, entra en esta carpeta y selecciona **Add file > Upload files**. Para facilitar los enlaces, usa nombres cortos sin espacios, por ejemplo `cancion-grado.mp3`.

GitHub Pages publicará esos archivos en `https://leopl72001.github.io/invitaciones-grado-pro/musica/`. Tras completar el workflow de despliegue puedes pegar el enlace público de cada archivo en **Personalización > Música de las invitaciones** y pulsar **Probar audio (5 s)** y **Guardar cambios**.

**Importante:** este repositorio y los archivos publicados son públicos. No incluyas grabaciones de terceros sin autorización. El almacenamiento de invitados/confirmaciones aún requiere conectar Supabase; esta carpeta solo es para archivos estáticos.
